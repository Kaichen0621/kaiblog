# 📱 KAI macOS 電腦裡有什麼 `/app`

- 最後更新：2026-07-26 16:50
- **總共 `46` 個 軟體**

## 這是我在 Mac 上的軟體清單
- Addictive Drums 2 Demo : 好用鼓音源，五月天用
- After Effect : 製作特效軟體
- Media Encoder 2026 : 用 `Adobe` 的軟體匯出好像得用它
- Affinity : 製作縮圖常用，[可以看這篇文章](/blog/affinity)   
- Anytype : 超好用開源筆記軟體，載入速度極快、同步方便！
- Aria Player : `Finale` 的 音源工具之類的吧？
- Audacity : 免費開源超好用的音訊編輯器 
- ClipGrab : 下載任何影片超好用！包含 B 站之類的
- Cubase 15 : 主要的編曲軟體，教學資源不錯   
- DaVinci Resolve 21 : 找不到比他更好的調色與剪輯軟體了   
> 超級耗電的剪輯軟體，21 終於出來了
- Discord : 聊天與語音頻道首選
- Final Cut Pro : 剪輯簡單的影片會用它，達芬奇要開很久
> 想不到用它來跟朋友一起看柯南，居然不會有延遲   
- Finale 27 : 停止提供更新了，但我依然習慣它
> 最近跳過去 `musescore`了   
- Gemini : 那個... 要 AI 得時候挺方便的，而且很快速 (我設定 按右邊兩下 `command`)
- GIMP : 支援多格式免費開源的修圖軟體，其實很好用 (曾老師使用 2.6.8 版本)
- Groove Agent SE : Cubase 內建的鼓機   
- Guitar Rig 7 : Kontakt 免費送的效果器，很高級很好用
- HALion Sonic : Cubase 內建音源，電量低   
- HandBrake : 處理影片畫質開源好幫手！
> 好像還可以做很多事但我不知道，去看 PAPAYA 
- IINA : 開源萬能播放器，Mac 必裝   
- iZotope RX 11 : 處理~~人生~~ `人的聲音` 超級好用的工具
- Keka : 超好用壓縮工具！RAR 打得開～
- Keynote : 蘋果簡報工具   
- Kontakt 8 : 強大的採樣音源主機 
- Line : 必要但笨重的通訊軟體   
> 台灣人已經習慣使用它了 : 
- LocalSend : 傳輸檔案好工具
> 突然覺得可替代 Blip
- Logic Pro : 蘋果自家 DAW，想刪除了！   (錄音老師推薦不要刪)
- Microsoft Edge : 最近開放用 Google 登入，才開始使用的
- Microsoft Excel : 強大的試算表工具   
> 安排行程我都用它
- Microsoft PowerPoint : 簡報必備工具   
> 還是比較喜歡 `Keynote`
- Microsoft Word : 業界標準文書軟體   
> 最近要開始學習了，因為需要用這個學習歷程
- Motrix : 免費速度快得下載器
- Musescore 4 : 開源打譜軟體
> 還是不會用他的排版工具 
- Native Access : 官方的入庫管理工具
> 很後悔沒有裝... 因為他會修復我壞掉的音色  
- Numbers : 蘋果表格工具
> 完全不會用   
- OBS : 強大的開源螢幕錄影與直播軟體   
> 後來發現建議不要買 Screen Studio
- OpenBVE : 開源模擬駕駛遊戲
> 不要問我為什麼會裝這個
- Pages : 蘋果文件排版工具
> 之前寫每日練習記錄表都用這個挺好用的，後來直接全面使用 `Obsidian`   
- Parallels Desktop : Windows 虛擬機，效能強大   
> 最近想安裝 `macOS 27 beta` 檔案都下載好了，結果根本在 PD 上面打不開
- Pearcleaner : 乾淨卸載 App 的利器，[教學看這裡](/docs/macAPPS/pearcleaner)
- Raycast Beta : 至少比 Spolight 好用，V2.0 超級好用
- Roblox : 我唯一玩的遊戲    
- Steinberg Library Manager : 管理 VST 音色庫路徑與授權的工具   
- Vibe : 語音轉文字用 Whisper 開源挺方便的
- Vovious : 調音準很方便，媲美 Melodyne
- VSCodium : 還是開源的文字編輯器好用
