# 📱 KAI macOS 電腦裡有什麼 `/app`

- 最後更新：2026-07-26 16:50
- **總共 `46` 個 軟體**

## 這是我在 Mac 上的軟體清單

1. Addictive Drums 2 Demo : 好用鼓音源，五月天用
2. After Effect : 製作特效軟體
3. Media Encoder 2026 : 用 `Adobe` 的軟體匯出好像得用它
4. Affinity : 製作縮圖常用
5. Anytype : 超好用開源筆記軟體，載入速度極快、同步方便！
6. Aria Player : `Finale` 的 音源工具之類的吧？
7. Audacity : 免費開源超好用的音訊編輯器
8. ClipGrab : 下載任何影片超好用！包含 B 站之類的
9. Cubase 15 : 主要的編曲軟體，教學資源不錯
10. DaVinci Resolve 21 : 找不到比他更好的調色與剪輯軟體了
11. Discord : 聊天與語音頻道首選
12. Final Cut Pro : 剪輯簡單快速影片時很好用、有效率！但是我不太會用
13. Finale 27 : 停止提供更新了，最近沒什麼在用
14. Gemini : 那個... 要 AI 得時候挺方便的，而且很快速 (我設定 按右邊兩下 `command`)
15. GIMP : 支援多格式免費開源的修圖軟體，其實很好用 (曾老師使用 2.6.8 版本)
16. Groove Agent SE : Cubase 內建的鼓機
17. Guitar Rig 7 : Kontakt 免費送的效果器，很高級很好用
18. HALion Sonic : Cubase 內建音源，電量低
19. HandBrake : 處理影片畫質開源好幫手！
20. IINA : 開源萬能播放器，Mac 必裝
21. iZotope RX 11 : 處理人生`人的聲音` 超級好用的工具
22. Keka : 超好用壓縮工具！RAR 打得開～
23. Keynote : 蘋果簡報工具
24. Kontakt 8 : 強大的採樣音源主機
25. Line : 必要但笨重的通訊軟體
26. LocalSend : 傳輸檔案好工具
27. Logic Pro : 蘋果自家 DAW，想刪除了！ (錄音老師推薦不要刪)
28. Melodyne Element : 修音必備好用插件
29. Microsoft Edge : 最近開放用 Google 登入，才開始使用的
30. Microsoft Excel : 強大的試算表工具
31. Microsoft PowerPoint : 簡報必備工具
32. Microsoft Word : 業界標準文書軟體
33. Motrix : 免費速度快得下載器
34. Musescore 4 : 開源打譜軟體
35. Native Access : 官方的入庫管理工具
36. Numbers : 蘋果表格工具
37. OBS : 強大的開源螢幕錄影與直播軟體
38. OpenBVE : 開源模擬駕駛遊戲
39. Pages : 蘋果文件排版工具
40. Parallels Desktop : Windows 虛擬機，效能強大
41. Pearcleaner : 乾淨卸載 App 的利器
42. Raycast Beta : 至少比 Spolight 好用，Beta 版功能強大 / 搜尋檔案好用
43. Roblox : 我唯一玩的遊戲
44. Steinberg Library Manager : 管理 VST 音色庫路徑與授權的工具
45. Vibe : 語音轉文字用 Whisper 開源挺方便的
46. Vovious : 調音準很方便，媲美 Melodyne
47. VSCodium : 還是開源的文字編輯器好用
