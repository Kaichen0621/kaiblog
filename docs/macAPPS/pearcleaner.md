## 解除安裝

每次解除安裝軟體都是直街把軟體宜到 ~~勒色桶~~ 垃圾桶嗎？根本槍清不乾淨，甚至可能還會有殘留檔案！

這時候就推薦使用 `PearCleaner`! **此軟體完全開源免費！** 該軟體分成 9 個部分～
|No.| English | 名詞解釋 |
|---|--------|-------|
| 1.| Apps | 刪除應用程式 |
| 2.|Developer | 刪除開發者殘留檔案 |
| 3.| File Search | 檔案搜尋 |
| 4.| Homebrew | Brew 套件清理 |
| 5.| Lipo | 節省軟個占用空間 |
| 6.| Orphans | 單獨殘留檔案清理 |
| 7.| Packages | 套件管理器 |
| 8.| Plugins | 外掛程式管理器 |
| 9.| Services | 服務管理器 |

希望這樣有比較好懂～

### | 1.| Apps | 刪除應用程式 |
