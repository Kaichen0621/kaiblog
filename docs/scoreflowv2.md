# 超強翻譜工具 (目前更新：Version 2.0)

立即網頁體驗！
## 為什麼要開發？
現在在這個數位時代，我們同學不是人手一台筆電就是一台平板，我同學出國前跟我介紹一款APP 可以翻譜，可是要錢，我就在想是不是可以自己設計！

所以就這樣開發出來了！

## 使用方式

應該不用多介紹吧？

| 按鈕 | 介紹 | 技巧 |
| --- | --------------- | ----------- |
| 打開 PDF 樂譜 | 可開啟本機 PDF 檔案   | 沒有技巧可言 |
| 模式：實體鍵盤 / MIDI | 可切換：`實體鍵盤 / MIDI` 以及 `AI 眨眼控制` | 電腦可使用快捷鍵 空白鍵 切換模式 |
| 深色譜面 | 可切換深淺模式  | 我是不知道有沒有人會這樣看啦！ |
| 偏好設定 | 可設定參數  | 使用 `AI 眨眼控制` 時可進入設定，切換成另一個就是 **搖頭控制**，但我不知道會不會有人用～ |
| 全螢幕 | 方便閱讀譜  | 有個按鈕在右上角可以退出全螢幕 (電腦可按 `F` 來切換) |
