## H 標題
我很喜歡使用 H 標題請看下面

## H2 標題
### H3 標題
#### H4 標題
##### H5 標題
###### H6 標題

---
語法：

``` md
# H1 標題
## H2 標題
### H3 標題
#### H4 標題
##### H5 標題
###### H6 標題
```
## 斜體 / 粗體 / 斜粗體 / 刪除線
使用 **斜體 / 粗體 / 斜粗體** 可讓文字變得好辨識

舉例來說：    
今天我去看了一部電影 *名偵探柯南 X 墜落的高速公路天使* 超級好看，故事主角的**口頭禪超帥**！
然後因為我不會日文，所以跟你們說他的~~狗~~口頭禪是：***新機子哇咿兜子***什麼東西的

---
語法：

``` md
今天我去看了一部電影 *名偵探柯南 X 墜落的高速公路天使* 超級好看，故事主角的**口頭禪超帥**！
然後因為我不會日文，所以跟你們說他的~~狗~~口頭禪是：***新機子哇咿兜子***什麼東西的
```

## 筆記 / 條列式 / 數字條列
接著是 筆記 / 條列式 / 數字條列 他們能讓讀者看得比較輕鬆（？

舉例來說：

你們知道狗的英文是什麼嗎？
> DOG ！

其實狗有很多種狗：   
- 比特犬
- 貴冰狗
    - 娃娃狗？
- 獵犬

好啦我不熟！   
但我知道 ：
1. OAOA
2. 孫悟空

這兩首必唱曲，在 5525 沒有一場不唱的！

---

其實狗有很多種狗：
