# 🎸 五月天 阿信相片館 | Mayday Ashin Gallery

一個輕量、響應式且具備 IG 風格的五月天阿信主題相片收藏館。支援圖片自動壓縮儲存、分類標籤管理、愛心按讚互動、檢視/編輯模式切換，以及 Firebase 雲端資料庫全自動實時同步。

## ✨ 核心特色

- **⚡️ 全自動實時雲端同步**：整合 Firebase Realtime Database 監聽機制（`onValue`），無論是照片、標籤分類、愛心按讚還是下載數，任何裝置一打開或修改，全網使用者無感即時同步。
- **☁️ 雙重同步保障**：背景全自動監聽之餘，介面保留「☁️ 手動同步」安全按鈕，隨時一鍵強制寫入備份，充滿安全感。
- **❤️ 愛心按讚與互動**：使用者可針對喜愛的照片點擊愛心按讚，愛心數與下載次數均即時廣播並同步儲存於雲端資料庫。
- **📸 快捷貼上與自動壓縮**：支援直接使用鍵盤快捷鍵 (`Cmd + V` / `Ctrl + V`) 貼上剪貼簿圖片，並透過 Canvas API 自動將檔案壓縮，兼顧畫質與載入速度。
- **🏷️ 全同步標籤管理**：可自由新增、重新命名或刪除相片分類標籤，標籤庫同步儲存於 Firebase，並支援依標籤即時篩選與內文關鍵字搜尋。
- **🌓 深淺色主題切換**：內建深色（Dark）與淺色（Light）視覺模式，自動記憶使用者的主題偏好。
- **✏️ 雙重模式（檢視 / 編輯）**：可一鍵切換「檢視模式」與「編輯模式」，防止日常瀏覽時誤觸刪除或編輯按鈕。
- **📱 響應式設計 (RWD)**：專為行動裝置優化的底部導覽列與彈性網格排版，在手機與電腦端皆能獲得極佳的視覺體驗。

## 🛠️ 技術棧

- **前端**：HTML5, CSS3 (原生變數 & Grid/Flexbox), ES6+ JavaScript
- **字型**：Google Fonts (`Plus Jakarta Sans`, `Noto Sans TC`)
- **雲端資料庫**：Firebase Realtime Database (Web SDK v10)
- **本地儲存 / 圖像處裡**：LocalStorage + HTML5 Canvas API (用於圖像 Resize 壓縮)
